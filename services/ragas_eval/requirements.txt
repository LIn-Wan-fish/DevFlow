# 这些版本是**实测钉死的**,不是随手写的。
#
# ragas 与本项目主程序的 langchain 栈无法共存:
#   - ragas 0.2+ / 0.3+ / 0.4+ 导入时就引用 langchain_community 已移除的
#     chat_models.vertexai -> ModuleNotFoundError
#   - ragas 0.1.x 能导入,但会把 langchain 从 1.x 强行降到 0.2.x,主程序随即报
#     Reviver.__init__() got an unexpected keyword argument 'allowed_objects'
# 所以这里锁死在 "ragas 0.1.x + langchain 0.2.x" 这一组自洽的组合,
# 并且**必须**放在独立容器里,不能让它的依赖树影响主程序。
ragas==0.1.22
langchain==0.2.17
langchain-core==0.2.43
langchain-community==0.2.19
langchain-openai==0.1.25
fastapi>=0.115
uvicorn[standard]>=0.32
