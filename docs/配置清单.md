## 附录:本机环境的两个坑

**1. Docker Desktop 必须从开始菜单启动。** 由脚本/终端拉起的话,那个会话结束时可能被连带终止
(现象:`docker info` 突然连不上,`wsl -l -v` 显示 `docker-desktop` 变 `Stopped`)。这个会话里被杀过三次。

**2. GitHub 加速器(Steam++ / Watt Toolkit)会让容器连不上 GitHub。**
它把 github 域名写进 hosts 指向 `127.0.0.1`,而**容器里的 127.0.0.1 是容器自己**;它还做 TLS 中间人。
一键方案:

```powershell
pwsh -File scripts/enable-github-accelerator.ps1
```

**只有 `DATA_SOURCE=github` 时才需要。** ⚠️ 这等于让容器信任一个本地中间人根证书,默认不开启。
